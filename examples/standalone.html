Integrasi 1 baris

Tempel snippet berikut sebelum </body>. Ganti PK_ANDA dengan public key agent dari dashboard (Builder → tab Integrasi), dan sesuaikan host API bila tidak memakai proxy Next.js. 

<script src="http://localhost:8000/embed/widget.js" data-sapa-key="PK_ANDA" defer></script>
💡 Bila frontend Next.js Sapa AI ikut di-deploy (port 3000), gunakan src="https://domain-anda/embed/widget.js" — request widget otomatis di-proxy ke backend sehingga bebas masalah CORS/cookie.

API programmatic (server-to-server) juga tersedia:

curl -N -X POST http://localhost:8000/w/PK_ANDA/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"halo, ongkir ke Bandung?"}'
